# Lean formalization workspace

This directory contains two separate formalization tracks:

- EPlusPi.lean: defines the real number \(e+\pi\) and states, but does not claim to prove, its transcendence.
- AlgebraicClosure.lean: proves closure of algebraic elements under addition and multiplication, and proves that roots of polynomials with algebraic coefficients are algebraic.

## Algebraic-closure result

The development reuses Mathlib's canonical predicate IsAlgebraic K x, meaning that a nonzero polynomial over K vanishes at x.

The general root theorem has the following mathematical statement. Let K and A be fields, with A an extension of K. If p : A[X] is nonzero, every coefficient of p is algebraic over K, and x : A satisfies aeval x p = 0, then x is algebraic over K.

Its proof is organized around the intermediate subalgebra generated by all coefficients of p. That subalgebra is algebraic over K; after viewing p as a polynomial over it, the root is algebraic over the intermediate subalgebra; Mathlib's scalar-restriction theorem then descends algebraicity to K.

This is a reusable proof architecture, not a claim that the underlying classical theorem is new mathematics. The file also exposes wrapper theorems for addition, multiplication, and the subalgebra of algebraic elements.

## Reproducible toolchain

The project pins Lean v4.36.0-rc2 and Mathlib v4.36.0-rc2. The GitHub Actions workflow first installs the pinned toolchain and runs lake update to generate the dependency manifest, then runs the Mathlib cache, lake build, and an axiom audit.

For a local build from the repository root:

    lake update
    lake exe cache get
    lake build

The algebraic-closure file ends with #print axioms commands, so its dependency lists are visible in the Lean build log. The workflow additionally audits the project namespace against Mathlib's standard allowlist of propext, Classical.choice, and Quot.sound.

A completed proof claim requires a successful CI run and inspection of the axiom audit. No source-level sorry, admit, or project-specific axiom is intended.
