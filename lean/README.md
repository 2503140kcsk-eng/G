# Lean formalization workspace

This directory contains two separate formalization tracks:

- `EPlusPi.lean`: defines the real number \(e+\pi\) and states, but does not claim to prove, its transcendence.
- `AlgebraicClosure.lean`: proves closure of algebraic elements under addition and multiplication, and proves that roots of polynomials with algebraic coefficients are algebraic.

## Algebraic-closure result

The development reuses Mathlib's canonical predicate `IsAlgebraic K x`, meaning that a nonzero polynomial over K vanishes at x.

The general root theorem states: let K and A be fields, with A an extension of K. If p : A[X] is nonzero, every coefficient of p is algebraic over K, and x : A satisfies `aeval x p = 0`, then x is algebraic over K.

### Proof architecture

The Lean proof uses the full algebraic-closure subalgebra `Subalgebra.algebraicClosure K A` as an intermediate coefficient ring (not merely the subalgebra generated by the finitely many coefficients):

1. Every coefficient of p belongs to this subalgebra by the coefficient hypothesis.
2. `Polynomial.toSubring` reinterprets p as a polynomial over the intermediate subalgebra.
3. The root equation and nonzeroness transfer to that polynomial, so x is algebraic over the intermediate subalgebra.
4. `IsAlgebraic.restrictScalars` descends algebraicity to K because the intermediate subalgebra is algebraic over K.

The result works for every finite-degree nonzero polynomial and avoids explicitly constructing minimal polynomials. This is a reusable formal proof architecture built from established Mathlib results, not a claim that the underlying classical theorem is new mathematics.

The file also exposes wrapper theorems for addition, multiplication, and the subalgebra of algebraic elements, plus a reusable algebraic-tower lemma.

## Verification

The project pins Lean `v4.36.0-rc2` and Mathlib `v4.36.0-rc2`. The GitHub Actions workflow installs the pinned toolchain, runs `lake update` to generate the dependency manifest, retrieves the Mathlib cache, builds all default targets, and audits axioms.

For a local build from the repository root:

    lake update
    lake exe cache get
    lake build

The successful CI run verifies that both `AlgebraicClosure` and `EPlusPi` build. `#print axioms` reports only `propext`, `Classical.choice`, and `Quot.sound` for the four principal theorems. The `axiom-audit` step audited 10 declarations under `AlgebraicClosure` and accepted all dependencies under the same allowlist.

No source-level `sorry`, `admit`, or project-specific axiom is used in the algebraic-closure development.
